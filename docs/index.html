Shopping assistant

Connect your own Claude API key. The assistant runs on Anthropic's API, which is billed per use and is separate from a claude.ai subscription. Create a key in the Claude Console, then paste it here.

The key is saved in this browser only and is sent only to Anthropic. It is not part of the site, so other visitors cannot use it.
